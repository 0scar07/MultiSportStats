## 📸 Vista General

| Página | Descripción |
|--------|-------------|
| 🏠 **Dashboard** | Panel central con partidos en vivo, próximos encuentros y tabla de posiciones resumida |
| 📊 **Live Matches** | Vista detallada de todos los partidos en curso con filtro por deporte |
| 🏅 **Standings** | Tablas de posiciones completas por liga y temporada |
| ℹ️ **About Us** | Información del proyecto y el equipo |

---

## ✨ Características

- **🔴 Marcadores en tiempo real** — Partidos en vivo de fútbol, baloncesto, tenis, hockey y F1
- **🗂️ Filtros por deporte** — Navega fácilmente entre La Liga, NBA, NHL, Roland Garros y más
- **📋 Tablas de posiciones** — Estadísticas completas: partidos, victorias, empates, derrotas, goles y puntos
- **📅 Próximos encuentros** — Calendario de los siguientes partidos con hora y fecha
- **🎨 UI moderna** — Sidebar de navegación, diseño responsive y badges de estado en vivo
- **🔐 Autenticación** — Páginas de login y registro incluidas

## 🚀 Cómo usar

1. **Clona el repositorio**
   ```bash
   git clone https://github.com/tu-usuario/multisport-stats.git
   ```

2. **Abre el proyecto**
   ```bash
   cd multisport-stats
   ```

3. **Lanza en tu navegador**
   ```bash
   # Abre directamente
   open "MultiSport Stats/login.html"

   # O con Live Server en VS Code
   # Click derecho → "Open with Live Server"
   ```

> No requiere instalación de dependencias ni servidor backend — es 100% HTML, CSS y JS estático.
